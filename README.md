# Widget boards and sticky notes!

How to use:
1. click on open project folder
2. click on my demo link
3. you can expand and move around the widget by holding the bottom right button on it
4. click on the text on sticky note to change to your own to-do list!
5. you can also type in the colour you want by pressing theme
6. the plant grows each time a task is completed!
